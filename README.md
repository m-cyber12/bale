# 🏆 ربات مدیریت گروه آلفا

ربات مدیریت گروه برای **بله**، **تلگرام** و هر **پیام‌رسان دلخواه** (از راه وب‌هوک) —
با موتور **هوش مصنوعی رایگان (OpenRouter)** برای مدیریت هوشمند گروه.

- 🐍 فقط کتابخانه‌ی استاندارد پایتون (بدون وابستگی اجباری)
- 🔐 هیچ توکنی در کد نیست — همه از **Environment**
- ☁️ آماده‌ی دیپلوی روی **Render** (و Railway/Heroku/VPS)
- 🧠 هوش مصنوعی فقط برای **مدیریت گروه** (نه بازی، نه سرگرمی)

---

## ✨ امکانات

**مدیریت گروه:** بن/سکوت/اخطار/اخراج، قفل‌های محتوایی (لینک، فوروارد، عکس، …)،
ضداسپم، ضدفحش، کلمات ممنوعه، حالت شب/خواب، حالت آهسته، عضویت اجباری،
سفیدلیست، یادداشت، قوانین، دستور سفارشی، تگ، فوروارد همگانی، پاک‌سازی.

**سرگرمی:** دوز، مافیا، جرئت‌وحقیقت، تاس، سکه، جوک، لاتاری، آزمون، گیف‌ساز، لقب.

**آمار و سطح:** XP، سطح، رتبه‌بندی روزانه/هفتگی/ماهانه، لیدربرد، دعوت‌ها، گزارش هفتگی.

**هوش مصنوعی (فقط مدیریت گروه):**
- پیام اخطار/سکوت/بن/اخراج **متن تازه** و مطابق سابقه‌ی همان کاربر
- **پرونده‌ی هر عضو**: تاریخ عضویت، درجه، تخلف‌ها، لحن (با هر تخلف سخت‌تر)
- **دستیار مدیریت**: `هوش مصنوعی وضعیت گروه چطوره؟`
- **حرف زدن با ربات**: روی هر پیام ربات ریپلای کن و سؤالت را بنویس → همان‌جا
  با هوش مصنوعی جواب می‌دهد (با حافظه‌ی ۳ گفتگوی آخر و شخصی‌سازی لحن)
- چرخش خودکار بین ۱۰+ مدل رایگان OpenRouter — **هیچ‌وقت پیام خطای لیمیت نمی‌بینی**

## 🚀 شروع سریع (۳ خط)

```bash
export BALE_TOKEN="123456:ABC..."          # توکن ربات
export TELEGRAM_TOKEN="789:XYZ..."         # اختیاری
export OPENROUTER_API_KEY="sk-or-v1-..."   # اختیاری (هوش مصنوعی)
export OWNER_ID="123456789"                 # آیدی عددی خودت (یا: OWNER_USERNAME=Spinner5698)
python3 main.py
```

هر پیام‌رسانی که توکنش را بگذاری، خودکار فعال می‌شود. برای انتخابی:

```bash
export PLATFORMS="bale,telegram"     # چند پیام‌رسان همزمان
export PLATFORM="bale"               # فقط یکی
export PLATFORMS="webhook"           # فقط وب‌هوک (پیام‌رسان دلخواه)
```

## ⚙️ متغیرهای محیطی

| متغیر | کار |
|---|---|
| `BALE_TOKEN` | توکن ربات بله (`BOT_TOKEN` قدیمی هم کار می‌کند) |
| `TELEGRAM_TOKEN` | توکن ربات تلگرام |
| `WEBHOOK_TOKEN` | رمز ورودی وب‌هوک (اختیاری) |
| `WEBHOOK_SEND_URL` | آدرس ارسال برای پیام‌رسان دلخواه |
| `PLATFORMS` / `PLATFORM` | کدام پیام‌رسان‌ها فعال باشند |
| `OPENROUTER_API_KEY` | کلید هوش مصنوعی (اولویت بر کلید پنل) |
| `OWNER_ID` | آیدی عددی مالک ربات — در پیوی ربات بنویس «آیدی من» تا بگیری |
| `OWNER_USERNAME` | جایگزین `OWNER_ID`: فقط نام کاربری مالک (مثلاً `Spinner5698`) |
| `DATA_DIR` | پوشه‌ی داده‌ها (روی Render با دیسک: `/var/data`) |
| `PORT` | اگر ست باشد، وب‌سرور سلامت/webhook بالا می‌آید |

نمونه‌ی کامل: [.env.example](.env.example)

> ⚠️ توکن ربات قبلی که در گیت‌هاب لو رفته بود، از کد حذف شد — در BotFather باطلش کن.

## 🌐 پیام‌رسان دلخواه (وب‌هوک)

هر پیام‌رسانی که JSON بفرستد/بگیرد وصل می‌شود:

```bash
export WEBHOOK_SEND_URL="https://my-bridge.example.com/send"
export WEBHOOK_TOKEN="یک-رمز-دلخواه"
export PLATFORMS="bale,webhook"
```

**ورودی** → `POST /webhook/webhook` (هدر `X-Webhook-Token`)

```json
{"chat_id": "-100123", "chat_type": "group", "chat_title": "گروه من",
 "user_id": 555, "user_name": "علی", "text": "سلام", "message_id": 1}
```

**خروجی** → ربات به `WEBHOOK_SEND_URL` می‌فرستد:

```json
{"method": "sendMessage", "chat_id": "-100123", "text": "سلام 👋",
 "parse_mode": "Markdown", "reply_to_message_id": 1}
```

پل تو `{"ok": true, "result": {"message_id": 99}}` برگرداند و تمام.
(سه شکل ورودی پذیرفته می‌شود: ساده، `event`، و خام بله/تلگرام.)

افزودن پیام‌رسان با API اختصاصی: یک زیرکلاس از `platforms.base.Platform`
بنویس و با `platforms.register_class(...)` ثبتش کن — بقیه‌ی ربات خودکار
با آن کار می‌کند (چون همه‌ی ارسال‌ها از `api.py` رد می‌شوند).

## 🩺 سلامت و مانیتورینگ

| مسیر | کار |
|---|---|
| `GET /` | صفحه‌ی ساده‌ی «ربات روشن است» |
| `GET /healthz` | JSON کامل: پلتفرم‌ها، وضعیت AI، مصرف امروز، گروه‌ها |
| `GET /version` | لیست آداپتورها و پلتفرم‌های فعال |
| `POST /webhook/<key>` | دریافت آپدیت |

بدون لو دادن توکن — فقط `api_host` و `configured: true/false`.
